# Aplikasi React Pertama saya - Modul 1.2

Aplikasi web modular yang dibangun menggunakan reaact dan vite.

## Fitur Aplikasi:
- Tombol Counter interaktif berbasis state
- kolom input nama dengan sapaan real-time 
- struktur kode modular terpisah di folder component 

## cara menjalankan proyek 
1. buka terminal terpisah di folder proyek 
2. jalankan perintah 'npm run dev'
3.  akses alamat di browser : 'http://localhost:5173'

# Aplikasi React Pertama - Modul 1.3
